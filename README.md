# Happy Birthday, Mader

A little birthday website for Mader's 44th, built with React + Vite.

- Text, photos, song and videos are all set in `src/content.js`.
- Photos go in `public/photos/`, the song in `public/music/`, videos in `public/video/`.
- Every push to `main` rebuilds and publishes the site to GitHub Pages.

Run it locally:

```bash
npm install
npm run dev
```
